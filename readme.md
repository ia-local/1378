# 🏛️ Projet 1378 : Enquête Parlementaire & Audit CNCCFP

Ce dépôt vise à centraliser les données, les preuves et les modèles analytiques dans le cadre d'une procédure d'enquête portant sur les flux financiers du parti "Ensemble" et les mécanismes de financement liés aux Accords de Paris (2015).

## ⚖️ Fondements Juridiques de l'Enquête

Notre investigation s'appuie sur le croisement des données de la CNCCFP avec les qualifications pénales suivantes :
1. **Détournement de fonds publics** (Art. 432-15 du Code pénal)
2. **Prise illégale d'intérêts** (Art. 432-12 du Code pénal)
3. **Escroquerie financière et manœuvres frauduleuses** (Art. 313-1 du Code pénal)
4. **Irrégularités de financement politique** (Art. L. 113-1 du Code électoral)

**Objectif final :** Démonter les mécanismes de régulation financière du climat issus des Accords de Paris par l'audit comptable et viser, à terme, un argumentaire légal pour l'abrogation des lois de ratification qui y sont liées.
